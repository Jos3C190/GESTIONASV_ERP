1.4 Definiciones

ERP: Sistema que integra los procesos administrativos y operativos de una organización.

Retaceo: Proceso mediante el cual se distribuyen costos adicionales de una compra (flete,
seguros, impuestos, gastos aduanales, etc.) entre los productos adquiridos para obtener el
costo real de cada artículo.

RBAC: Modelo de control de acceso basado en roles.

API REST: Conjunto de servicios que permiten la comunicación entre aplicaciones utilizando
HTTP.
